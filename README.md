# Our Stage — Website giới thiệu CLB

Website giới thiệu chính thức của CLB Our Stage, triển khai độc lập trên Cloudflare Pages. Không liên quan tới website quản lý OSC trên Vercel.

## Cloudflare Pages
- Production branch: `main`
- Framework: `None`
- Build command: `npm run build`
- Build output directory: `dist`

Nội dung trang chủ nằm tại `content/site.json`; nội dung các hoạt động tại `content/events/`. Cấu hình Pages CMS nằm trong `.pages.yml`.

> Trước khi công khai, BCN cần thay hình ảnh và liên kết mẫu bằng nội dung chính thức của CLB.
